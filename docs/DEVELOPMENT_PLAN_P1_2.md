# P1.2 多源知识接入与版本治理开发计划

## 已确认的产品口径

1. Agent 固定在拓扑图下方；展开高度由 250px 降为 200px，移动端由 330px 降为 264px。
2. “工作方式”只作为消息区顶部的注释。普通回答与待审查内容显示在同一消息流中；待审查内容是带状态、证据与操作摘要的特殊 Agent 回复，不是另一个对话框。
3. Agent 提供“本地图谱深度搜索”和“总结当前对话”两个动作。前者生成只读构建候选，后者提取与当前节点相关的短知识摘要。
4. 知识卡片拆为理论知识、应用知识、其他知识、历史修改四页。历史页仅展示最近 15 条短摘要；检索默认排除历史，只有用户明确要求查看时才能访问。
5. 多源输入先归一化为来源资料、内容片段和知识声明，再交给知识检索 Agent 与审查 Agent 判断应创建节点、关系或续写卡片。原始二进制只保存存储引用与校验值。
6. 通用 LLM 只负责回答和结构化提取，不拥有图谱仓库写权限；内置 Agent 负责编排、审查、构建预览和用户确认后的提交。
7. 图谱使用可迁移的版本化知识包管理。工作变更不会自动成为保存点，只有用户明确确认“保存版本”才建立检查点；最多保留 1 个最近版本和 2 个历史版本。回滚也需确认，并把恢复结果保存为新的最近版本。

## 按序开发与验收

1. 冻结 P1.1 基线并建立独立 ZIP。**已完成。**
2. 重构 Agent 紧凑消息流，加入对话总结。验收：桌面 200px、移动 264px，两个操作并列，待审查是特殊消息。
3. 重构四类知识卡片。验收：分类稳定、空分类有说明、历史最多 15 条且默认不进入 Agent 检索。
4. 建立多源接入与知识候选契约。验收：对话摘要和论文文本可形成带来源的候选；图片、音频、视频、文档可由适配器接入；无 Key 时不影响静态应用。
5. 完成结构化仓库、通用 LLM/内置 Agent 权限边界。验收：数据可导入导出，写入必须经过审查和用户确认。
6. 完成用户主动保存与两历史版本回滚。验收：最多保存 3 个检查点，只暴露最近版本之前的 2 个回滚目标；回滚建立新的最近版本，独立审计日志不因检查点轮换而删除。
7. 运行全部测试、构建、代码规范、桌面与 390px 移动端检查，完成独立审查、Git 标签与 ZIP 交付。

## 当前版本边界

P1.2 提供离线可运行的图谱、结构化多源接入基础、可测试的 Agent 工作流与版本仓库。
真实模型推理、OCR、语音识别、论文解析和外部检索由可替换适配器承接；未配置服务时，界面明确显示本地只读结果，不伪装成联网检索或正式写入。
