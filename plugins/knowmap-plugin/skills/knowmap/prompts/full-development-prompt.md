在原网络上继续研究，保留确认过的根、域和节点身份。逐节点观察缺口、检索、提出有证据的候选、再观察覆盖度。每个节点作为新的局部根时，独立重置轮次、局部观察、静默计数和局部新增节点预算；不得继承祖先或历史节点的消耗。新增节点进入待访问队列，之后也获得同样完整的扩展能力。多个缺口分批处理，统一合并时解析重复名称、临时 ID 和跨批父级。

每批先把候选放入无卡片的层级骨架：优先复用或建立 category 中间类别，再生成具体节点。逐父节点统计直接子节点；超过 maxPrimaryChildren（默认8）时先按单一稳定维度重组。高度相关节点先检查能否成为父子或有方向的类型边，再检查共同上位类别，只有同抽象级且互不包含时才作为同级。不得使用从总根累计的 maxDepth 截断；主要域至少选一条代表路径继续追问到语义不可再分，通常不少于6层。结构通过后才扩写卡片，避免细节生成反过来决定分类。

80–150节点为参考目标，不设输出上限。构建由宿主 LLM 分批完成，禁止调用项目已配置的 DeepSeek/其他 Provider。每批保存到项目外隔离任务目录，达到宿主预算时保留成果并列出剩余缺口，不能声称收敛。
